# Method

## Data: a clean source domain and a laboratory-like target proxy

`src/csdgap/simulator.py` implements a constant-interaction model (CIM) of a double quantum dot. For gate coordinates on a 64 x 64 grid the ground-state charge configuration (n1, n2) minimises

U(n) = 0.5 E1 n1^2 + 0.5 E2 n2^2 + kappa n1 n2 - n1 eps1 - n2 eps2,

with lever arms that include gate cross-talk. The transition-line mask is the exact boundary between ground states (dilated to about 3 pixels). The image is the signal of a capacitively coupled charge sensor (a charge stability diagram, CSD), built from thermally broadened (Boltzmann-weighted) occupations.

A flat vector of 11 parameters controls everything (see `PARAM_NAMES`): temperature, white noise, 1/f noise in raster time, weight/centre/width of a Coulomb-peak sensor response, probability and size of telegraph charge jumps (which shift the voltage axis on whole scan lines, so the labels move with them), mean inter-dot coupling, mean cross-talk and a background tilt.

- **Source domain**: textbook values (almost sharp transitions, tiny white noise, linear sensor).
- **Target proxy**: the same family with harsher values, a lever-arm asymmetry the fitted model does not contain, and an *unmodelled-artefact strength* `m` in {0, 0.5, 1} that adds diagonal interference stripes and an abrupt sensor re-tuning part-way through the scan. No real measurement is used.

## Methods compared

| Method | Uses target images? | What it does |
|---|---|---|
| source-only | no | train on clean simulation (the standard physics baseline) |
| augment | no | hand-set noise, blur, brightness ramp and contrast gain on clean images (classical domain randomisation; ranges fixed in advance, never tuned on the target) |
| generative adversarial network (GAN) translator | N unlabeled | unpaired CycleGAN-style translator (least-squares loss, cycle weight 10, residual generator) from clean to target-like images; labels are inherited from the source image |
| physics-fitted (this study's focus) | N unlabeled | differential evolution fits the 11 simulator parameters so that 24 image statistics (quantiles, gradient quantiles, radial power spectrum, row-shift lag histogram, drift statistics) match the N target images; labels come from the fitted simulator and are exact for it |
| oracle | labelled | trained on 768 target-proxy images with their true labels (upper bound) |

Every method trains the same downstream model (a 0.12 M-parameter U-Net (convolutional encoder-decoder network), binary cross-entropy plus Dice loss, 150 steps) on 768 images and is tested on 512 held-out target-proxy images that are identical for all methods and seeds of a given `m`.

## Metrics

- Dice coefficient of line segmentation (primary).
- *Gap closed* = (Dice method - Dice source-only) / (Dice oracle - Dice source-only), computed per seed.
- Random-feature Fréchet distance (RF-FD, scaled by 1000) between 512 generated images and 512 held-out target images, in the feature space of a fixed random convolutional network; it is deliberately different from the 24 statistics the fit optimises.
- Adaptation cost: wall-clock seconds of the fit or the GAN training (three seeds run in parallel on one graphics processing unit (GPU), so seconds are comparable within this study only).

## Experiments

1. **Scaling and robustness sweep**: N in {8, 32, 128} unlabeled target images by artefact strength `m` in {0, 0.5, 1}, all methods.
2. **Ablation** (N = 32, m = 0.5): freeze one component of the fitted model at its source value (thermal broadening, sensor peak, charge jumps, physics shift) and refit the rest.
3. **GAN budget check** (N = 32, m = 0.5): the same GAN trained for 800 instead of 180 steps, to test whether the GAN baseline is merely under-trained.
4. **Seeds**: 3 seeds (0, 1, 2); a seed changes the training images, the unlabeled target subset, the fit and GAN initialisation, and the U-Net initialisation. Results are mean +/- sample standard deviation over seeds.

## Fairness notes

- The fit and the GAN get the same unlabeled images and the GAN gets a comparable (short) wall-clock budget; the longer GAN run quantifies how much this matters.
- The target proxy is generated by the family the fit searches, so the fit is favoured at `m = 0`. The artefact sweep and the lever-arm asymmetry exist to take that favour away step by step.
- The only physics baseline is the constant-interaction model; there is no quantum-circuit component in this study.
